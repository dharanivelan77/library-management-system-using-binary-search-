⚡ Binary Search Algorithm

DAA implementation used in this project.

What is Binary Search?

Binary Search is an efficient searching algorithm that works on a sorted array. It repeatedly divides the search interval into two halves.


Algorithm

1. Sort books according to Book ID.
2. Set LEFT = 0.
3. Set RIGHT = n - 1.
4. Find MIDDLE = (LEFT + RIGHT) / 2.
5. Compare the target Book ID with MIDDLE.
6. If equal → Book Found.
7. If target is greater → Search RIGHT half.
8. If target is smaller → Search LEFT half.
9. Repeat until LEFT > RIGHT.
10. If LEFT > RIGHT → Book Not Found.

Complexity Analysis

Best Case: O(1)

Average Case: O(log n)

Worst Case: O(log n)

Space Complexity: O(1)
